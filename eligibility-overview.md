# Eligibility

## Registration eligibility

* `npq-senior-leadership`
* `npq-headship`
* `npq-executive-leadership`
* `npq-early-years-leadership`
* `npq-leading-teaching`
* `npq-leading-behaviour-culture`
* `npq-leading-teaching-development`
* `npq-leading-literacy`
* `npq-leading-primary-mathematics`
* `npq-additional-support-offer`
* `npq-early-headship-coaching-offer`
  - must have completed `npq-headship`
  - must be a headteacher
* `npq-senco`

## Funding eligibility

* `npq-senior-leadership`
  - must be in England
  - must not have already completed this course
* `npq-headship`
  - must be in England
  - must not have already completed this course
* `npq-executive-leadership`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list]
* `npq-early-years-leadership`
  - must be in England
  - must not have already completed this course
* `npq-leading-teaching`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list]
* `npq-leading-behaviour-culture`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list]
* `npq-leading-teaching-development`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list] **and** are taking on the
    role of lead mentor for an ITT provider
* `npq-leading-literacy`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list]
* `npq-leading-primary-mathematics`
  - must be in England
  - must not have already completed this course
  - if you work in a school on [eligibility list]
* `npq-additional-support-offer`
  - must be in England
  - must not have already completed this course
* `npq-early-headship-coaching-offer`
  - must be in England
  - must be in the first 5 years of headship
  - must not have already completed this course
* `npq-senco`
  - must be in England
  - must not have already completed this course
